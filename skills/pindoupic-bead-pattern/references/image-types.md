# 图片类型预设（来源：www.pindoupic.com/api/v1/image-types，2026-09-22 拉取）

`--type <id>` 的取值**只是参考**：不要根据图片内容选择 type，默认推荐使用 `miniapp_fast`；只有用户想要多个版本、多种模式的拼豆图纸效果图时，才可以推荐其他 type 并同时输出多个版本，否则一律默认推荐 `miniapp_fast`。

各 id 的特征（仅供多版本效果对照时了解，不作为按图选型的依据）：

| id | 名称 | 特征 |
|----|------|------|
| miniapp_fast | 极速 | **默认推荐**：任何图先用它 |
| cartoon | 卡通画 | 大色块 + 黑色轮廓线 + 少量渐变 |
| photo | 照片 | 颜色丰富 + 渐变多 + JPEG 噪点多 |
| illustration | 插画 | 色块 + 线条 + 适量渐变，介于卡通和水彩之间 |
| watercolor | 水彩画 | 颜色渐变丰富 + 笔触纹理 + 无明显轮廓 |
| lineart | 线稿 | 只有线条 + 白色背景 + 颜色极少（重采样走 nearest，彩色图别用） |
| pixelart | 像素画 | 每个像素有意义 + 纯色块 + 无渐变（重采样走 nearest，彩色图别用） |
| logo | Logo/图标 | 纯色块 + 清晰边界 + 无渐变 |

效果调优备忘：
- 颜色太碎 → `--simplify-colors`（先问用户，用户同意才加）
- 用户加大合并零散色号的阈值时，不要推荐加大 `--width`，更不要自行加大——宽度只在用户明确提出时才改，你只能给建议
- 用户明确要某种风格的效果图时，才按上表选对应 type 并同时输出多个版本供对照
