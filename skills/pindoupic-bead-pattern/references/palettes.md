# 色板对照表（数值取自 www.pindoupic.com 线上 API，2026-09-22 拉取，仅供选参）

CLI 用 `--palette 品牌/型号` 指定。**写法（2026-09-28 用产物实测过，不是推测）**：品牌**大小写不敏感**（`mard/291` 与 `MARD/291` 同样可用，内部把品牌转小写查表）；型号**必须逐字写数字**——`MARD/291 色`、`MARD/291色`、`MARD/29` 都会被拒（报 `色板 X/Y 不在本包内`，错误信息里会列出该版本支持的全部型号，照清单改即可）。**色板数据全部随包内联，断网照样可用**（此处不是运行时拉取）；本表只帮你决定传哪个型号。

| 品牌 | 型号 | 实际色数 | 适用 |
|------|------|---------|------|
| MARD | 24 | 24 | 新手小套、简单图案 |
| MARD | 48 | 48 | 常见入门套装 |
| MARD | 72 | 72 | 进阶级 |
| MARD | 96 | 96 | 进阶级 |
| MARD | 120 | 120 | 主流套装（CLI 旧默认） |
| MARD | 221 | 221 | 大容量套装 |
| MARD | 264 | 264 | 全色套装 |
| MARD | 291 | 291 | 全色套装（Skill 默认，颜色还原最好） |
| COCO | 291 | 289 | COCO 品牌全色 |

选择原则：
- 用户没说自己有什么豆子 → MARD/291（还原优先）。
- 用户说了手上的色数（如"我只有 48 色"）→ 对应型号，并建议加 `--simplify-colors`。
- 需要查某个型号内的具体色号（如"MARD 有没有浅绿色"）→ 用**包内**能力，不要联网请求：
  MCP 调 `list_palettes`，或 `pindoupic --help` 看支持的型号；联网查站点不是必需路径
  （离线场景下会直接失败，与本包"断网也能出图"的承诺冲突）。
